# 100件令人烦恼的小事儿（配图版）— 设计文档

日期：2026-07-27

## 目标

一个可在 iPhone 与电脑端都良好展示的静态 HTML 网页，展示「100件令人烦恼的小事儿」，每条含标题、描述、配图。整体风格：可爱、卡通、浪漫。带一首背景音乐（钢琴曲 ogg）。内容会陆续更新，需保证后续添加的便利性。

## 核心决策

- **更新方式**：集中式数据文件 `data.js`。用户只需改这一个文件 + 往 `配图/` 丢图。
- **布局**：响应式卡片瀑布流（电脑多列 / 平板 2 列 / iPhone 单列）。
- **卡片交互**：点击卡片弹出大图窗，显示大图 + 完整标题 + 完整描述。
- **缺图处理**：`image` 留空时自动显示可爱占位图（柔和渐变 + emoji/卡通图案）。
- **背景音乐**：右上角悬浮唱片/音符按钮，点击播放/暂停并循环，播放时图标转动。符合浏览器自动播放限制，手机/电脑均不报错。

## 文件结构

```
100_little_cases/
├── index.html          # 页面骨架
├── style.css           # 可爱卡通浪漫风格样式
├── app.js              # 渲染卡片、弹窗、音乐开关逻辑
├── data.js             # ★用户唯一需要改的内容文件
├── 配图/                # ★用户放配图的目录（已存在）
│   └── 洗衣机脏了.png
└── 演奏曲-【钢琴演奏】周杰伦与昆凌英国教堂婚礼的钢琴音乐.ogg   # 背景音乐
```

用户日常只碰两处：往 `data.js` 加一段、往 `配图/` 丢图。其余文件无需改动。

## 数据格式（data.js）

```js
const CASES = [
  { id: 1, title: "洗衣机的滚筒好脏好脏", desc: "明明没用几次呢", image: "配图/洗衣机脏了.png" },
  { id: 2, title: "耳机线总是缠成一团", desc: "明明放进去时是好好的…", image: "" }, // 没图→自动占位
  // 以后加新的，复制一行改内容即可
];
```

字段说明：
- `id`：数字，用于排序与弹窗定位。
- `title`：小事标题。
- `desc`：描述文字（长短皆可，卡片显示前几行，弹窗显示全文）。
- `image`：配图相对路径（如 `配图/xxx.png`）；留空则显示可爱占位图。

## 视觉风格（可爱·卡通·浪漫）

- 配色：奶油粉 + 淡紫 + 薄荷绿的柔和渐变；圆角、柔和阴影。
- 字体：手写感/圆润中文字体。
- 装饰：飘动的爱心/星星小装饰；卡片 hover 轻微上浮 + 摇摆。
- 顶部标题区：大标题 +一句副标题。

## 布局（响应式瀑布流）

- 电脑：3–4 列瀑布流；平板：2 列；iPhone：单列。
- 卡片内容：配图（或占位图）+ 标题 + 描述前两行（超出省略）。
- 点击卡片 → 弹出大图窗：大图 + 完整标题 + 完整描述，背景虚化，点空白处/× 关闭。

## 背景音乐

- 右上角悬浮按钮（唱片/音符图标）。
- 点击一次：开始循环播放；再点：暂停。
- 播放时图标旋转动画。
- 遵循浏览器自动播放策略（需用户手势触发），iPhone 与电脑均不报错。

## 技术约束

- 纯静态：HTML + CSS + 原生 JS，无构建步骤、无外部依赖（字体可用系统字体或内联）。
- 直接双击 `index.html` 或用简单静态服务器即可打开。
- 图片文件名含中文，需正确处理（相对路径引用，浏览器自动 URL 编码）。
